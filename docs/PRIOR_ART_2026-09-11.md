# Songgot prior-art sweep — 2026-09-11

Hard gate before any "first" / "#1 in Korea" claim.
Method: Hugging Face Hub HTTP API (exact `safetensors.total` parameter counts, `createdAt`
timestamps, `cardData.license`), model cards read in full, GitHub API, arXiv, and Korean- and
English-language web search. Firecrawl and the HF MCP connector were down for this session; all
Hub facts below were pulled directly from `huggingface.co/api/*` and `huggingface.co/<repo>/raw/main/*`.

Everything below is sourced. Where nothing was found, the searches actually run are listed.

## VERDICT

1. **"First Korean tool-calling model" is FALSE.** Kakao shipped FunctionChat-Bench (2024-11) and
   `kanana-2-1.3b-instruct` (2026-07-27) publishes tool-calling scores; LG's `EXAONE-4.0-1.2B`
   (2025-07-11) does agentic tool use at 1.28B.
2. **"First from-scratch tiny Korean LM" is FALSE.** `Infinity08/KAWK-1.5-50M-Korean-Base` —
   51.5M, Korean-only, own Korean SentencePiece, scratch-pretrained — landed 2026-08-03, five weeks
   before us. `gaon12/haru` is 6.8M (2026-08-11); SKT's KoGPT2 was 125M in 2021.
3. **"Smallest Korean language model" is FALSE.** Haru v1.0 is 6.8M, v2.0 is 17.0M.
4. What survives is narrow and defensible: **the smallest openly-licensed Korean model whose
   stated purpose is tool calling, and the only one at 50M–126M with a published
   FunctionChat-Bench SingleCall number.** No one else at any size has published a
   FunctionChat-Bench SingleCall score for a sub-1B from-scratch Korean model.
5. Required qualifiers on every claim: **"openly licensed (Apache-2.0)"** (KAWK declares no
   license at all), **"trained from scratch"**, **"tool-calling"**, **"published benchmark
   number"**, and the size band **50M–126M**.
6. **Never say "best".** Our own card shows Qwen3-0.6B at 43.2 and Qwen3.5-0.8B at 45.2 against
   Songgot's 33.0–33.2 on the same harness. We are beaten by non-Korean models 5–6x our size.
7. **Never say "33.2% on FunctionChat-Bench" unqualified.** The official metric is LLM-as-Judge
   (GPT-4); ours is strict exact match with our own scorer. Say "under our exact-match scorer".
8. "First Korean model running in a browser" is unverified — claim the artifact
   (a WASM/GGUF PWA that works offline), not the primacy.
9. Songgot-V has more room: no Korean VLM under 1B has been found. But say "we found none",
   not "none exists", and check VARCO-VISION-2.0-1.7B-OCR before any OCR claim.
10. Safest public line: **"a 50M/126M from-scratch, Apache-2.0, Korean-first tool-calling model
    that runs offline in a browser — the smallest Korean tool-calling model we can find."**

## 2. Korean tool calling / function calling beyond FunctionChat-Bench

### FunctionChat-Bench itself — exact facts

- **FunctionChat-Bench** | Kakao Corp. | arXiv:2411.14054, submitted **2024-11-21** |
  GitHub https://github.com/kakao/FunctionChat-Bench created 2024-08-29, **last pushed
  2026-02-25** (still maintained), 123 stars | **Apache-2.0** |
  https://www.kakaocorp.com/page/detail/11415?lang=ENG
  — Authors: Shinbok Lee, Gaeun Seo, Daniel Lee, Byeongil Ko, Sunghee Jung, Myeongcheol Shin.
  **Composition, verified from the repo:** `FunctionChat-Singlecall.jsonl` holds **25 functions**,
  each with **4 single-turn prompts** = **100 prompts**; each prompt is run under **5 tool
  conditions** (`1_exact`, `4_random`, `4_close`, `8_random`, `8_close`) = **500 single dialogue
  turns**. `FunctionChat-Dialog.jsonl` holds **45 multi-turn dialog scenarios** scored across four
  situation types (call / completion / slot / relevance). Total 700 evaluation items.
  — A **third split was added after the paper** and is absent from it:
  `data/FunctionChat-CallDecision.jsonl`, **606 lines**, run via `evaluate.py common`
  (metrics Call / Reject / Slot-all / Slot-some). Anyone citing "700 items" is citing the 2024
  paper, not the current repo.
  — **CRITICAL:** "The FunctionChat-Bench utilizes a rubric evaluation method called
  **LLM-as-Judge, where OpenAI GPT-4 serves as the evaluator**" (`api_version: gpt-4-1106-preview`;
  paper states GPT-4-0125-preview, binary pass/fail; rubrics in `rubric_call.txt` /
  `_completion` / `_slot` / `_relevance`). Human reviewers corrected 5.5% of judgments on both
  SingleCall (218) and Dialog (88).
  *Significance for us: our 33.0–33.2 figures come from `eval/functionchat_exact.py`, strict exact
  match on name + arguments — a different and stricter metric than the official GPT-4 rubric.
  Our numbers are NOT comparable to any officially-reported FunctionChat-Bench score and must
  never be presented as one.*

#### A dangerous numerical coincidence — brief this before any launch

arXiv:2509.19369 Table 5 (**Multi-chain Call Accuracy, its own private Korean dataset,
LLM-as-Judge over 5 runs**) reports **GPT-4o-mini 33.0**, EXAONE-4.0-32B-AWQ 32.6, Qwen3-14B 28.4,

scorer. Anticipate and pre-empt this conflation in every writeup.

## 7. What a fair claim looks like

### Claims we CAN defend, with the exact qualifiers

Every one of these needs the full qualifier string. Dropping any clause makes it false.

1. **"The smallest openly-licensed Korean model built for tool calling that we can find —
   50M and 126M parameters, trained from scratch, Apache-2.0."**
   Qualifiers doing the work: *openly-licensed* (excludes KAWK, which declares none, and Kakao /
   LG / Naver custom licences), *built for tool calling* (excludes Haru 6.8M, ssiat 255M,
   SproutKO 154M, KAWK 51.5M — all smaller-or-equal but none does tool calling),
   *that we can find* (never "the only", never "the first in the world").

2. **"The only Korean tool-calling model under 500M parameters with a published benchmark
   number."** True as of 2026-09-11. Nearest competitors with tool calling:
   `KoGum-0.5B` 709M (no numbers, author calls it a failure), `LFM2-350M-ToolLLaMA` 354M
   (English ToolBench, fine-tune), `EXAONE-4.0-1.2B` 1.28B, `kanana-2-1.3b` 1.29B.

3. **"33.0–33.2% call accuracy on Kakao's FunctionChat-Bench SingleCall under our own
   exact-match scorer (500 items, 5 tool conditions), not the official GPT-4 LLM-as-Judge
   rubric."** The scorer caveat is mandatory.

4. **"A Korean-first 32k tokenizer at 0.90 tokens per Hangul syllable, against Gemma 3 at 0.98,
   Qwen3 at 1.15 and Needle 2 at 3.47, measured on the same 100 FunctionChat SingleCall queries."**
   This is a measurement we ran; it is defensible as stated, scoped to those 100 queries.

5. **"Runs offline in a browser and on a phone — GGUF f16 / Q8_0 / Q4_K_M in the repo, PWA with
   a service worker."** Claim the artifact, not primacy.

6. **"Licence-clean: Apache-2.0 weights, no closed-model outputs in training, FunctionChat-Bench
   used for testing only with a disjointness gate."** This is genuinely rarer than the size claim
   and is worth leading with.

### Recommended public one-liner

> Songgot is a 50M/126M-parameter Korean-first tool-calling model trained from scratch under
> Apache-2.0, small enough to run offline in a browser. It scores 33.0–33.2% call accuracy on
> Kakao's FunctionChat-Bench SingleCall under our own exact-match scorer — the smallest Korean
> tool-calling model with a published benchmark number that we could find.

## CLAIMS WE CANNOT MAKE

Each line is followed by the specific evidence that kills it.

1. ~~"Korea's first tool-calling / function-calling model."~~
   Kakao published FunctionChat-Bench in 2024-11 (arXiv:2411.14054) and ships tool calling in
   `kanana-2-1.3b-instruct`; LG's `EXAONE-4.0-1.2B` (2025-07-11) reports BFCL-v3 55.7.

2. ~~"The first Korean model trained from scratch at tiny scale."~~
   `Infinity08/KAWK-1.5-50M-Korean-Base`, 51.5M, own Korean SentencePiece, scratch-pretrained,
   2026-08-03 — 38 days earlier. `gaon12/haru` 6.8M, 2026-08-11. `skt/kogpt2-base-v2` 125M, 2021.

3. ~~"The smallest Korean language model."~~ Haru v1.0 is 6,793,363 params — 5.7x smaller than
   Songgot-nano.

4. ~~"The first Korean model at 125M / 126M parameters."~~ SKT KoGPT2 has been a 125M Korean
   decoder since ~2021.

5. ~~"The first from-scratch Apache-2.0 Korean tiny model."~~ `MOGODIK/ssiat-1.0`, 254.7M,
   apache-2.0, tagged `from-scratch`, 2026-09-01. `gaon12/haru` is MIT.

6. ~~"The first Korean from-scratch model with tool calling."~~ `jiwon9703/KoGum-0.5B-16k-Instruct`
   (709M, apache-2.0, 2026-03-05) is from scratch with `<tool_call>` support;
   `LLM-OS-Models/KoHRM-Text-1.4B` (apache-2.0, 2026-05-23) is scratch-pretrained for tool use.

7. ~~"The best Korean tool-calling model at any size."~~ ~~"Beats models N times our size."~~
   Our own model card records Qwen3-0.6B at 43.2 and Qwen3.5-0.8B at 45.2 versus Songgot's
   33.0–33.2 on the identical harness. We lose to non-Korean models 5–6x our size.

8. ~~"Scores 33.2% on FunctionChat-Bench."~~ (unqualified) The official benchmark metric is
   LLM-as-Judge with `gpt-4-1106-preview` against four rubric files. Ours is strict exact match
   from `eval/functionchat_exact.py`. Different metric; not comparable to published FunctionChat
   numbers.

9. ~~"No one else is working on Korean tool calling."~~ KOPA-Bench (arXiv:2609.05395,
   2026-09-04, 145 Korean public-API multi-step tasks) is one week old; `space1637/iapyx-*`
   shipped Korean function-calling fine-tunes in 2026-07.

10. ~~"The first Korean on-device model."~~ Kakao explicitly markets `kanana-2-1.3b-instruct`
    (2026-07-27) as "for on-device deployment"; Naver markets HyperCLOVA X SEED 0.5B for
    "mobile applications, smart home devices and wearable devices"; `ssiat-1.0` documents
    Raspberry Pi Zero 2W operation.

11. ~~"The first Korean model that runs in a browser."~~ Unverified — we did not confirm this
    either way. Claim the artifact (offline PWA + GGUF), not the primacy.

12. ~~"Songgot-V will be Korea's first small VLM / first Korean document VLM."~~ Do not pre-claim.
    NCSOFT shipped `VARCO-VISION-2.0-1.7B-OCR` on 2025-07-08. Re-run this sweep before any
    Songgot-V claim.

13. ~~"Number one in Korea"~~ / ~~"국내 최초"~~ / ~~"세계 최초"~~ in any form, for any of the above.
    No Korean leaderboard ranks tool calling, so there is no board on which we hold a position.
